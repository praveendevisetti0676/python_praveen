# Super 30 Python Loop Task 3

## Objective

Apply Python loops to realistic data-processing and problem-solving
scenarios.

This task focuses on using `for` loops, `while` loops, nested loops,
conditions, lists, dictionaries, functions, and user input to solve
practical programming problems.

## Programs

### 1. Calculate Total Transaction Value

-   Calculate the total value of transactions using a loop.
-   Do not use `sum()`.

### 2. Find Highest and Lowest Transaction

-   Find the highest transaction using a loop.
-   Find the lowest transaction using a loop.
-   Do not use `max()` or `min()`.

### 3. Calculate Average Temperature

-   Calculate the total temperature using a loop.
-   Calculate and display the average temperature.

### 4. Student Marks Analysis

Analyze student marks and count how many students scored: - 90+ -
75--89 - 50--74 - Below 50

### 5. Login System with 3 Attempts

Create a simple login system that: - Allows a maximum of 3 password
attempts. - Displays a successful login message for the correct
password. - Locks the account after 3 unsuccessful attempts.

### 6. Filter Products Above ₹2,000

Use a dictionary of products and prices. Print only products costing
more than ₹2,000.

### 7. Accept 10 Numbers and Store in a List

-   Accept 10 numbers from the user.
-   Use a loop to store the numbers in a list.
-   Display the final list.

### 8. Character Frequency Counter

Count the frequency of every character in a string without using
`Counter`.

Example:

``` text
Input: banana

b -> 1
a -> 3
n -> 2
```

### 9. Find Second-Largest Number

Find the second-largest number in a list: - Use loops. - Do not use
`sort()`.

### 10. Check Palindrome Using Loops

Check whether a given string is a palindrome using loops.

Examples:

``` text
madam -> Palindrome
python -> Not a palindrome
```

### 11. Create Number Pattern

Create the following pattern using nested loops:

``` text
1
12
123
1234
12345
```

### 12. Basic ATM Simulation

Create a basic ATM simulation that repeatedly allows the user to: -
Check balance - Deposit money - Withdraw money - Exit

The ATM program is organized using functions for better readability and
maintainability.

## Program Requirements

-   Each Python program is independently executable.
-   Loops are used wherever required.
-   Restricted built-in functions such as `sum()`, `max()`, `min()`,
    `sort()`, and `Counter` are avoided for the specified problems.
-   The ATM program is organized using separate functions rather than
    one large code block.

## How to Run

Make sure Python 3 is installed.

Run any program from the repository using:

``` bash
python filename.py
```

For example:

``` bash
python 05_login_system.py
```

or:

``` bash
python 12_atm_simulation.py
```

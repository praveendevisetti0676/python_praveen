# 🧩 Core Python Concepts Demonstrated

The projects progressively demonstrate how basic Python concepts can be combined to build useful applications.

### 1. Functions

Functions are used to divide a program into smaller, reusable pieces.

```python
def calculate_total(items):
    # calculation logic
    return total
```

### 2. Loops

Loops are used when an operation needs to be repeated.

```python
for item in items:
    process(item)
```

and:

```python
while condition:
    # repeat operation
```

### 3. Conditional Logic

Conditional statements allow the program to make decisions.

```python
if condition:
    ...
elif another_condition:
    ...
else:
    ...
```

### 4. Data Structures

The projects make practical use of:

* Lists
* Dictionaries
* Strings
* Tuples
* Numeric data

### 5. Validation

User input is validated before processing to make applications more reliable.

### 6. Reusability

Common logic is moved into functions so that it can be reused instead of duplicated.

# 🚀 How to Run

## Option 1 — Jupyter Notebook

Install Jupyter Notebook:

```bash
pip install notebook
```

Start Jupyter:

```bash
jupyter notebook
```

Open the required `.ipynb` file and execute the cells sequentially.

## Option 2 — Visual Studio Code

1. Install Python.
2. Install [Visual Studio Code](https://code.visualstudio.com/).
3. Install the **Python** extension.
4. Open this repository.
5. Open any `.ipynb` notebook.
6. Select the appropriate Python kernel.
7. Run the cells.
